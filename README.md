# Portfolio 

# ROLE

Act as a Senior UI/UX Designer, Senior Frontend Engineer, Recruiter, and Portfolio Reviewer with 15+ years of experience hiring MERN Stack Developers.

# GOAL

Create a premium, ATS-friendly, responsive portfolio website that helps a fresher MERN Stack Developer stand out for internships and full-time roles.

The portfolio should look like something a product-based company candidate would have.

Technology Stack:

- React 19

- Vite

- JavaScript (No TypeScript)

- HTML5

- CSS3 (NO Tailwind CSS)

- React Router

- Framer Motion

- Lucide React Icons

- EmailJS (Contact Form)

- React Toastify

- Responsive Design

- Dark/Light Theme

- SEO Optimized

Use clean folder structure and reusable components.
